# Product Requirements Document (PRD)

## Overview
Shopee Price Tracker is a web application that monitors product prices on Shopee and sends alerts when prices drop.

## Features
- Track multiple products
- Set price thresholds
- Receive notifications
- View price history

## Tech Stack
- Backend: Node.js with Express
- Frontend: React
- Database: PostgreSQL
- Deployment: Docker
